# Nidhin Dev D — Modern Portfolio

## Run
Open `index.html` directly, or use any static server:
`python3 -m http.server 8000`

## Add your photos
Put your own images in `images/photos/`:
- `profile.jpg`
- `about.jpg`
- `gallery-1.jpg`
- `gallery-2.jpg`
- `gallery-3.jpg`

The site automatically falls back to existing portfolio images if a photo slot is empty.

## Pages
- Home — `index.html`
- About — `about.html`
- Designs — `designs.html`
- Projects — `projects.html`
- Contact — `contact.html`
- `work.html` is a compatibility redirect to Designs.

## Main features
- Responsive modern dark UI
- Animated scroll reveals
- Animated marquee
- Custom cursor on desktop
- Mobile navigation
- Project filtering
- Project detail modal
- Animated counters
- Photo slots
- No build step / no framework required
